# 作品档案 / Archive

这里按"原始照片 → 决策记录 → 最终作品"保存代表案例，而不是只陈列一面结果图墙。每份档案说明保留了什么、舍弃了什么，以及金墨和色彩如何从现场生长出来。

## 档案结构

每个案例一个文件夹：

```text
examples/
└── 01-案例名/
    ├── source.jpg    # 原始照片
    ├── result.jpg    # 最终作品
    └── notes.md      # 决策记录（见下方模板）
```

## notes.md 模板

```markdown
# 案例名

- skill：水墨成画 shuimo-ink-6.0 / 水墨相续 shuimo-graft-6.0
- 主主体：
- 必留关系：
- 摄影区 P：位置与大致占比
- 主出口：哪个形、从哪条边、往哪个方向
- 一个作者性决定：动势延伸 / 主动删减 / 形态合并 / 尺度调整 / 色彩转译 / 空间重组
- 强调色：色相、来源、承担的结构功能
- 金墨：落点、聚集→散开方向
- 舍弃了什么：
- 失败的尝试与修正（如有）：
```
