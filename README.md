# 水墨 · shuimo-6.0

**作者 / Author · @0cces-cc**

[English](README.en.md) · [日本語](README.ja.md) · [水墨成画 SKILL](skills/shuimo-ink-6.0/SKILL.md) · [水墨相续 SKILL](skills/shuimo-graft-6.0/SKILL.md) · [作品档案](examples)

同一张照片，可以画成一整张水墨画海报，也可以在保留原图主要元素的基础上，由原图延伸出水墨画。本仓库收藏了两个版本的文生图 Skill，共用一套水墨化生成标准。

- **水墨成画 · shuimo-ink-6.0** —— 以原图为准，生成一整幅完整的水墨海报。照片只提供事实、关系和气质；成品从头到尾都是画，不保留任何照片区域。
- **水墨相续 · shuimo-graft-6.0** —— 原图与水墨的拼接嫁接。保留一块连续的真实照片锚点区，让原图中的形跨过摄影边界、改变媒介，长成独立成立的水墨场域。

| | 水墨成画 | 水墨相续 |
|---|---|---|
| 照片的角色 | 唯一内容来源，成品全是画 | 成品中受保护的真实摄影层 |
| 结果 | 整幅现代水墨海报 | 真实照片 + 水墨嫁接为一件作品 |
| 调用 | `$shuimo-ink-6.0` | `$shuimo-graft-6.0` |

## 核心纪律（两个 skill 共用）

不堆规则，先做决策，只把本图需要的东西交给模型：

1. **决策先行**：成画走"定锚点 → 定核心命题 → 选一个作者性决定 → 写意延伸"；嫁接走"执行卡"，按 C → P → H → I → M 的顺序——先定全幅构图 C，再锁定主主体、摄影区 P / 交接区 H / 水墨区 I、主出口和材料落点 M。缺失的事实标"未知"，不补成景物。
2. **先连形、后换材、再放开**（嫁接专属）：接口落到具体位置——哪个形、从哪条边、往哪个方向出去；出界时锁住方向、粗细、明暗和分叉关系；进入水墨区远端才允许放大、合并、收笔。
3. **五段短提示词**：目标 500–900 中文字符，一个事实只写一次，只保留本图选定的机制。
4. **单变量纠偏**：失败时定位首要失败项，只替换对应段落，不向提示词尾部追加补丁。

## 水墨标准速览

- 暖白生宣 `#f7f4ea`，纤维颗粒可见，不做旧；
- 墨分五色（焦 `#1a1712` / 浓 `#2e2a22` / 重 `#57503f` / 淡 `#8f8671` / 清 `#c9bea4`），禁纯黑；
- 干湿浓淡焦完整层次，落墨顺序湿 → 淡 → 重 → 浓 → 焦；
- 长而连贯的笔势，2–8 个关键笔势立形，枯笔飞白；
- 三层颗粒（纸纤维 / 墨颗粒 / 金墨），只有一个颗粒焦点区；
- **金墨**：矿物颗粒局部铺附，聚集 → 过渡 → 散开，粗中细颗粒并存，间隙露墨，不做闪光滤镜；
- 单一矿物强调色做结构（朱砂 / 石青 / 石绿 / 藤黄 / 赭石 / 胭脂 / 花青），暖中性墨为绝对主角；
- 现代编辑插画气质，不仿古、不落款、不印章。

完整规则见各 skill 的 [references/](skills/shuimo-ink-6.0/references)。**两个 skill 共用同一份 `ink-standard.md`**（内容完全相同的双副本，以 shuimo-ink-6.0 那份为母版，修改时两边同步）；墨法标准 = 宣纸 / 墨分五色 / 完整墨法表 / 笔触气质 / 画种占比 / 三层颗粒 / 金墨三层结构 / 单一强调色 / 留白。graft 专属规则（摄影区保护、C → P → H → I → M 执行顺序、跨界交接）在 graft 自己的 SKILL.md 与 handoff.md 里。

## 安装

```bash
git clone https://github.com/0cces-cc/shuimo-6.0.git
cp -R shuimo-6.0/skills/* ~/.codex/skills/   # Claude 系宿主对应 ~/.claude/skills/
```

如果 Skill 没有立即出现，重启宿主。

## 使用

```text
用 $shuimo-ink-6.0 把这张照片画成一整幅水墨海报。
```

```text
用 $shuimo-graft-6.0 把这张照片接成水墨。保留树干与屋檐的关系。
```

除图片外，默认返回一句中文创作说明；只要提示词也可以明说。

## 关于照片

Skill 只把你提供的照片作为当前生成任务的参考。除非明确要求，不浏览、分享、另行上传或保存原始照片。
