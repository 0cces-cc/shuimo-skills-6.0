# 水墨 · shuimo-6.0

**作者 / Author · @0cces-cc**

[中文](README.md) · [English](README.en.md) · [水墨成画 SKILL](skills/shuimo-ink-6.0/SKILL.md) · [水墨相续 SKILL](skills/shuimo-graft-6.0/SKILL.md) · [作品アーカイブ](examples)

一枚の写真は、一枚まるごとの水墨画ポスターにもなれば、原図の主要な要素を残したまま、原図から水墨画が伸びていく形にもなります。このリポジトリには、一組の水墨化生成基準を共有する、2 つのバージョンの文生図（text-to-image）Skill を収録しています。

- **水墨成画 · shuimo-ink-6.0** —— 原図を基準に、一枚まるごと完全な水墨ポスターを生成します。写真は事実・関係・気質だけを提供し、完成品は最初から最後まですべて絵であり、写真の領域は一切残しません。
- **水墨相续 · shuimo-graft-6.0** —— 原図と水墨画の継ぎ合わせ（グラフト）。連続した一帯の実写写真アンカー領域を残し、原図の中の形が写真の境界を越えて媒介を変え、独立して成立する水墨の場へと育ちます。

| | 水墨成画 | 水墨相续 |
|---|---|---|
| 写真の役割 | 唯一の内容ソース、完成品はすべて絵 | 完成品の中で保護される実写レイヤー |
| 結果 | 一枚まるごとの現代水墨ポスター | 実写写真 + 水墨のグラフトによる一つの作品 |
| 呼び出し | `$shuimo-ink-6.0` | `$shuimo-graft-6.0` |

## コアとなる規律（2 つの Skill 共通）

ルールを積み上げるのではなく、まず決断し、その画像に必要なものだけをモデルへ渡します：

1. **決断が先**：成画は「アンカーを定める → 核心テーゼを定める → 作者性的決定を一つ選ぶ → 写意で伸ばす」。継ぎ合わせは「実行カード」——主主体、写真区 P / 引継区 T / 水墨区 I、主な出口と材料の落とし所を固定します。欠けている事実は「未知」と記し、勝手に景物を補いません。
2. **先に形をつなぎ、次に材料を変え、最後に解放する**（継ぎ合わせ専用）：接点は具体的な位置に落とします——どの形が、どの辺から、どちらの方向へ出るのか。境界を出るときは方向・太さ・明暗・分岐関係を固定し、水墨区の遠端に入ってから初めて拡大・統合・収束を許可します。
3. **五段の短いプロンプト**：目標 500–900 字（中国語）。一つの事実は一度だけ書き、その画像で選定した機構だけを残します。
4. **単一変数による修正**：失敗時は第一の失敗項目を特定し、該当段落だけを差し替えます。プロンプトの末尾にパッチを追記しません。

## 水墨基準ダイジェスト

- 暖白の生宣 `#f7f4ea`。繊維の粒子が見え、古びさせない；
- 墨分五色（焦 `#1a1712` / 濃 `#2e2a22` / 重 `#57503f` / 淡 `#8f8671` / 清 `#c9bea4`）。純黒は禁止；
- 乾・湿・濃・淡・焦の完全な階層。落墨の順は 湿 → 淡 → 重 → 濃 → 焦；
- 長く連続した筆勢。2–8 本の決定的な筆で形を立て、枯筆・飛白を用いる；
- 三層の粒子（紙繊維 / 墨の粒子 / 金墨）。粒子の焦点区は一箇所だけ；
- **金墨**：鉱物粒子を局所的に堆積させ、聚集 → 過渡 → 散开。粗・中・細の粒子が混在し、隙間から墨が見える。キラキラしたフィルターにはしない。ひとつの連続した金墨区の内部でだけ聚散が起こり、画面に散らばらせない；
- 単一の鉱物アクセントカラーが構造を担う（朱砂 / 石青 / 石緑 / 藤黄 / 赭石 / 胭脂 / 花青）。暖かい中性墨が絶対的な主役；
- 現代的な編集イラストの気質。仿古・落款・印章はなし。

完全なルールは各 Skill の [references/](skills/shuimo-ink-6.0/references) を参照してください。**2 つの Skill は同一の `ink-standard.md` を共有**します（内容が完全に同じ複製。shuimo-ink-6.0 側が原本で、変更時は両方を同期）。graft 固有のルール（写真保護、P/T/I、境界引き継ぎ）は graft 自身の SKILL.md と handoff.md にあります。

## インストール

```bash
git clone https://github.com/0cces-cc/shuimo-6.0.git
cp -R shuimo-6.0/skills/* ~/.codex/skills/   # Claude 系ホストでは ~/.claude/skills/
```

Skill がすぐに現れない場合はホストを再起動してください。

## 使い方

```text
用 $shuimo-ink-6.0 把这张照片画成一整幅水墨海报。
```

```text
用 $shuimo-graft-6.0 把这张照片接成水墨。保留树干与屋檐的关系。
```

画像のほかに、デフォルトで短い中国語の制作メモを返します。プロンプトだけの納品も明示すれば可能です。

## 写真について

Skill は、提供された写真を現在の生成タスクの参照としてのみ使います。明示的な要求がない限り、写真を閲覧・共有・再アップロード・保存することはありません。
