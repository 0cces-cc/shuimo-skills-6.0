# 检查与单变量纠偏

仅在收到结果图、用户要求评审或要修改失败稿时读取。未见结果图，只能检查提示词，不能宣布图像通过。

## 按顺序过六道门

| 次序 | 检查对象 | 不通过的实际表现 |
|---|---|---|
| 1 | 来源事实 | 新增无依据主体；主体、动作或关系与原图/文字不符 |
| 2 | 反扫描复刻 | 姿势位置比例与原图几乎一致、背景逐项对应；逐物体换笔刷；轮廓摄影化、细节同等重要；只有笔刷改变没有信息取舍 |
| 3 | 墨色语言 | 只有透明模糊没有笔墨；无墨色层次或整体棕黄做旧；整张浅灰滤镜 |
| 4 | 笔势 | 主形不是连贯长笔；碎笔短笔反复描摹；长笔触变成大量细线 |
| 5 | 主次与色 | 多个焦点争夺、无安静区域、留白不足或无功能、彩色比墨更抢眼、强调色无结构作用 |
| 6 | 金墨 | 全图均匀细闪、金属描边、亮黄块、无聚集渐散或抢主形 |

## 修复映射：只改失败的那一层

| 症状 | 改哪一项 | 不要如何补救 |
|---|---|---|
| 描摹感重 | 回到核心命题与作者性决定，删更多次要信息，重组空间 | 不追加"更写意、更高级"形容词 |
| 画面太满 | 合并叶群/瓦片、删次要纹理、让留白承担功能 | 不只降低透明度 |
| 淡灰滤镜 | 强化浓墨立形 + 少量焦墨点睛，建立层次 | 不把全图涂黑 |
| 太像水彩 | 强化主形浓墨、焦墨和飞白，减少彩色面积 | 不新增第二主色平衡 |
| 没有主次 | 一个焦点做足，次重点改淡线简笔 | 不平均加细节 |
| 金墨太细 | 减少细粉，增加局部粗中颗粒、断续薄片与露底间隙 | 不提高全画闪光强度 |
| 金墨抢戏 | 缩小铺附区并减少呼应 | 不用加色来平衡 |

先返回一条最重要的失败诊断和对应改句。需要重试时替换相关段落，保留其余已通过部分；额外运行是否允许由用户授权与宿主成本规则决定，默认不无限自动重试。

## 交付检查

- 主体、动作与关系符合照片或文字依据；成品能认出原照片的"事实身份"。
- 发生了至少一个明确的作者性介入；不再是一一对应翻译。
- 暖白宣纸、长笔势、干湿浓淡焦、局部粒感、单一强调色、留白 ≥45% 成立。
- 金墨局部铺附；无题跋、印章、签名、水印。
- 只输出提示词时，明确尚未生成图像。
