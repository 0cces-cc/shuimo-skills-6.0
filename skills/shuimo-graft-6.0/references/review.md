# 检查与单变量纠偏

仅在收到结果图、用户要求评审或要修改失败稿时读取。未见结果图，只能检查提示词，不能宣布图像通过。

## 按顺序过七道门

| 次序 | 检查对象 | 不通过的实际表现 |
|---|---|---|
| 0 | 独立成画 | 水墨区没有自己的主势/墨块/空纸关系/收笔/视觉重心，读起来像照片被继续画出去的尾巴、像水墨滤镜、像半写实描摹 |
| 1 | 来源与模式 | 没有真实摄影区；成品读成整幅水墨而非照片嫁接；新增无依据的主体 |
| 2 | P 保真 | 原主体变化、全片调色或纸纹覆盖；需要像素保真却无保护/合成支持；照片边缘整圈被水墨同化、照片失去"真实照片面板"的并置感 |
| 3 | H 连续 | 出口错位、粗细跳变、方向折断、分叉增加、重复对象、遮挡颠倒 |
| 4 | 水墨语言 | 只有透明模糊没有笔墨；平均描叶描瓦；无墨色层次或整体棕黄做旧；**主体身份泄漏**——P 中完整具象主体的摄影身份被错误复制到 I 区，I 退化为该主体的半写实水墨重绘 |
| 5 | 主次与色 | 多个焦点争夺、无安静区域、彩色比墨更抢眼、结构色无作用 |
| 6 | 金墨 | 全图均匀细闪、多点分散铺开、金属描边、亮黄块、无聚集渐散或抢主形 |

**第 0 门只查构图独立，独立成画 ≠ 独立内容来源。** 允许：同一树干继续成为水墨主势、同一屋檐成为接口、同一人物姿态转译成笔势、同一空间关系继续存在；同景延伸、内容仍可辨认不判失败。不允许：P 的完整主体被重新复制一遍、I 变成 P 的半写实水墨滤镜、I 没有自己的构图只是在"续画"。


## 同景延伸不是第二场景

不要用"遮住照片还能认出建筑"作为否决标准。检查的是物体和空间是否被**重复建立**：

- 一个原有形从摄影进入墨、原图裁切外可见屋檐只在下方出现一次：允许。
- 上面完整表现主体，下方又完整复制相同主体及背景，两个独立视点或起点：失败。
- 水墨在构图上独立成立：允许，不等于必须在内容上断绝原图。
- 水墨局部与原图透视一致：允许，尤其交接处；完整纹理逐项照搬才需压缩。

## 修复映射：只改失败的那一层

| 症状 | 改哪一项 | 不要如何补救 |
|---|---|---|
| 接不上 | 改出口、裁切或统一变换；恢复方向、宽度、拓扑 | 不追加"更自然、更高级" |
| 接处由暗变白 | 让积墨承接原暗部，淡化放远端 | 不统一清墨起步 |
| 原片消失 | 恢复 P 或切换真实区域保护/合成流程 | 不靠加强写实形容词冒充原像素 |
| 幻觉景物 | 从内容账本删除无依据对象，收束其来源句 | 不扩大泛化禁词清单 |
| 水墨只是描摹 | 合并叶群/瓦片、删除次要纹理，保留连接骨架 | 不删光可辨认形体 |
| 水墨太小 | 拉长已有主势或扩大墨块影响范围 | 不增加另一棵树、另一座房子 |
| 水墨太满 | 删除辅助标记、松开背景、保留安静区 | 不只降低透明度 |
| 太像水彩 | 强化已有主形的浓墨、焦墨和飞白，减少彩色面积 | 不把全图涂黑 |
| 金墨太细 | 减少细粉，增加局部粗中颗粒、断续薄片与露底间隙 | 不提高全画闪光强度 |
| 金墨抢戏 | 缩小铺附区并减少呼应 | 不新增第二主色平衡 |
| 金墨分散铺开 | 收拢到一个连续金墨区，删除远处散点，聚集→散开只在这一个区内部发生 | 不扩大金墨总面积 |
| 照片边缘被同化 | 交接范围缩回主出口局部，恢复 P 其余边缘的清楚面板感 | 不用更多晕染去"统一"两种媒介 |
| 主体身份泄漏 | 删除 I 中对该主体的完整描绘，只保留局部接口结构，转入墨势/墨块/空纸 | 不用"更写意"的形容词掩盖 |
| I 只是续画没有构图 | 回到 C 阶段重立全幅构图：主势/次势/墨块/空纸/I 区视觉重心 | 不在尾部追加更多禁项 |

先返回一条最重要的失败诊断和对应改句。需要重试时替换相关段落，保留其余已通过部分；额外运行是否允许由用户授权与宿主成本规则决定，默认不无限自动重试。

## 真实验证的记录方式

在可生成的环境做回归验证时，固定同一输入、裁切、画幅、模型版本与支持的设置；若宿主不暴露种子就如实记录未知，不编造种子值。分别测试旧版与新版提示词，保存全部结果而非只选最好的一张；每例每版建议至少 3 次，按七道门记录通过/失败与简短证据。首轮只是小样本探索，不能据此保证跨模型稳定性。

"提示词静态一致""包结构合法""样例提示词写好"均不等于"出图效果已经通过"。
