# 中文短提示词编译

把决策转成可见动作，不把技能说明原文当提示词。先读输入与执行卡。以下方括号是写作槽位，交付前必须替换成已确定内容；无对应事实时删除该句，不能把槽位留给图像模型猜测。

## 五段结构，各有唯一职责

### 第一段：画布与身份

写画幅、P 的具体位置与保留内容、I 的去向、整体焦点和安静区。若还没有对保护区定位，先定位，不用"模型自行选择"代替执行卡。

句式：

> [比例]的现代水墨作品。[照片区域]作为一块真实照片面板保留[具体主体与关键关系]的真实摄影，保持原照片关系，不主动重绘/调色；宿主不支持区域保护时，不承诺像素级不变，不重绘也不覆盖纸墨，边缘除主出口外保持清楚。水墨向[方向]展开，焦点落在[位置]，在[位置]保留低信息空间。

### 第二段：同一个形如何跨界

这是最重要的一段，不可被材料形容词挤掉。写一个主入口和位置、方向、粗细/明暗、连接关系；非形体入口改写为实际明暗边界或空间走向。

> 原图[具体形及位置]从照片[具体边缘]继续进入纸面，接出处保持[方向、宽度/明暗、分叉或遮挡]，不是再起一个新对象。沿同一个形减少摄影细纹，转为[已选墨法]；到[远端]才[放大/合并/收笔]。

### 第三段：取舍与空间

写已选作者性决定、构图骨架、具象依据和明确省略项。列出本图确实要用的形，不列通用植物、山水、建筑菜单。

> 水墨区先立构图：主势[走向]，收笔在[位置]，墨块落在[位置]，空纸留在[位置]，视觉重心是[位置——不能只是 P 主体的完整重复；同一源形经新的墨势/墨块/疏密/空间组织重组后可以担纲]。仅使用[可证实形]，以[一个主要动作]组织；按类型省略：建筑删[窗格/砖瓦/栏杆/装饰线]，植物删[逐叶]，人物删[衣料纹理]，摄影纹理删[镜头锐度/噪点/细碎反光]；保留[结构骨架与接口必需形体]。[必要辅助形]只出现一次并退到次要层。延伸属于同一次连续构图，不另画第二套全景。

### 第四段：笔墨、纸与色

压缩成一段但不能只写"高级水墨"。至少包含：暖白宣纸、浓淡层次、干湿与长笔势、颗粒局部性，以及本图已确定的颜色和金墨位置。

> 暖白微米色宣纸，纤维可见而不做旧。湿淡墨退远，浓墨立形，少量焦墨点睛；长笔有起收，枯笔飞白与湿边相间，积墨内部有砂质颗粒。[单一矿物色]以有起收笔的饱和笔触沿[源形]承担[功能]；暖中性墨为主。金墨按三层结构只落在[落点]这一个连续区域：结构金线沿[已有轮廓]局部出现，矿物金块集中附着、边缘断裂露墨，金颗粒向外密度递减；不做闪光滤镜，与构图冲突时删金不删构图。

无金墨或无色彩依据时按本次明确需求删去对应句，不能反向编造高光、花或反光水面。

### 第五段：只保留本图相关禁项

默认覆盖：不重绘 P，不复制第二套场景，不新增无来源对象，不以全边模糊/毛边代替接口，不全图撒金，不新增文字与水印。

若用户只要五段提示词，就不要附上整份执行卡、文件路径、规则来源、工具说明或候选方案。能力限制放在提示词外单独说明。

## 弱指令跟随模型模式（如 Seedance）

弱指令模型不等于 prompt 更短，而是**并行决策更少、层级更明确**。已知模型容易把照片和水墨混成一片、或抓不住多条并行约束时，按以下优先级编译，每级只保留一两句：

1. **C**：整幅构图一句话——主势走向、P 的位置、I 区自己的视觉重心；
2. **P**：哪里是真实照片面板，哪里绝对不能改变；
3. **H**：只有一个主出口，明确从哪里出去；
4. **I**：把 C 的构图落到纸面——墨块 + 空纸 + 笔势安排；
5. **M**：材料与金墨——只保留必要墨法关键词（暖白纸、墨分五色、长笔势、枯笔飞白），金墨最后加入、仅一个聚焦区域。

不要并列塞入全部墨法、色彩与禁项——宁少勿散。标准五段结构给指令跟随较强的模型使用。

## 长度与修改纪律

- 目标 500–900 中文字符；必要时可放宽，但通常不超过 1200。字符预算是编排建议，不是生成成功保证。
- 写一个选定比例，不写所有比例；写一个入口，不写全套入口菜单。
- 一个事实写一次。不要在正文、最高优先级、负面词、最终总纲里重复同一禁令。
- 修改接缝就替换第二段；修改金墨就替换第四段对应句；修改事实就同时核对第三段。
- 不翻译成英文以求"更强"；默认中文。模型确有语言限制且用户同意时再提供对应译文。
- 先检查提示词静态一致性，再使用结果图验证实际表现。短并不自动等于稳定，长也并非唯一病因。
