# 笔墨与金墨标准（ink-standard）

> **SOURCE OF TRUTH**：本文件在 shuimo-ink-6.0 与 shuimo-graft-6.0 各持一份**完全相同**的副本。修改时以 shuimo-ink-6.0/references/ink-standard.md 为母版，改完同步到 graft。graft 专属规则（摄影区保护、P/H/I 结构、跨界交接）不在本文件，见 graft 的 SKILL.md 与 references/handoff.md。

## 宣纸底

采用**暖白、仅微带米色**的生宣（生宣本色，只比纯白暖一点点）：基准 `#f7f4ea`，范围 `#f4efdf` 至 `#faf8f0`，叠加**明显可见的纤维颗粒/纸纹肌理**（不是光滑、不是打印白）。

关键：是"暖白里带一点米色"，**严禁偏黄、暗黄、做旧**——黄一旦过头，整幅画就"旧"掉、失去现代感。也不要霉斑、褪色、扫描感、立体纸张阴影。

## 墨分五色（基于纸底，不是纯黑）

| 墨色 | 色值 | 层次 |
|---|---|---|
| 焦墨 | `#1a1712` | 最干最黑 |
| 浓墨 | `#2e2a22` | 厚重 |
| 重墨 | `#57503f` | 中间 |
| 淡墨 | `#8f8671` | 轻盈 |
| 清墨 | `#c9bea4` | 极淡 |

**禁纯黑 `#000000`**：一用就是"打印感"，不是水墨。色值是视觉参考，不是逐像素调色保证。暖中性墨不要被画成整张棕褐色。

## 干湿浓淡焦（笔触系统，画面的灵魂）

这是画面的灵魂，每一笔都要有干湿浓淡焦之分：

| 墨法 | 视觉特征 | 用途 |
|---|---|---|
| 焦墨 | 干、涩、浓黑、笔锋露骨、颗粒最强 | 点睛细节：苔点、眼睛、衣领、花蕊 |
| 浓墨 | 厚重、有体积 | 结构骨架：主体轮廓、山石 |
| 重墨 | 中间层次 | 过渡、暗部 |
| 淡墨 | 轻盈、远层 | 远山、云雾、花朵勾勒 |
| 湿墨/清墨 | 洇开、晕染 | 气氛层：水面、云雾、背景 |
| 枯笔/飞白 | 断笔、留砂、质感 | 树干、发丝、岩石纹理 |

- 执行顺序遵循落墨逻辑：**湿 → 淡 → 重 → 浓 → 焦**（后上的墨压先上的墨）。不要求画面从左到右依次排色。
- "浓淡干湿"不是灰度滤镜：它是墨量、水分、压力、边缘、叠压与纸面吸收的综合行为。
- 浓墨有体积，焦墨只点关键；背景用淡、清墨退开。保留近实远虚、近浓远淡、尺度和遮挡的纵深，空气感不能洗掉主结构。不能把整幅画做成淡淡的灰色滤镜。
- 边缘软硬相济：湿边可洇，焦墨与枯笔可清晰。

## 笔触气质

笔触要**长、连贯、一气呵成**，像一笔下来、行云流水。主体（尤其人物）用连贯的长笔触一笔带出，不要碎笔、短笔、反复描摹。断笔只用于枯笔飞白，不是碎笔。

**禁止把长笔触理解成大量细长线条**——目标是"一个动作留下来的痕迹"，不是"很多线组成的纹理"。人物尤其避免逐笔勾勒：用 **2–8 个关键笔势**完成主要形体，再以少量局部细节确认身份。2–8 是概括手段，不是全图笔数限制。枯笔的断续来自同一次书写的摩擦。

## 画种占比

每张图内部的笔法分配（风格配重，不是互斥分区或量化配额，不要把百分比抄入提示词）：

- **写意 ~42%**：主体造型的大写意笔触，笔简意足，画面骨架。专门负责把复杂细节概括成几笔——越是繁琐的纹理，越用写意省略，不逐笔照搬。
- **泼墨 ~28%**：背景气氛层，大面积泼洒晕染。
- **没骨 ~16%**：主体局部不勾线，直接用墨块/色块造型。
- **工笔 ~10%**：关键细节精细刻画。
- **白描 ~4%**：勾线。

## 颗粒：有三个层级，但只有一个重点

1. **纸纹颗粒**：全局、明显可感知（宣纸的糙、纤维细沙感，不是几乎看不见的低对比）。
2. **墨颗粒**：积墨、焦墨、枯笔和飞白内的砂质层（飞白砂、焦墨渣）。
3. **金墨**：三层结构，见下节。

**每张图至少 1 个"颗粒焦点区"（浓墨/焦墨处）。** 颗粒必须集中、有疏密。全图平均 = 没有重心 = 变成"图标"——这是要避免的最大问题。

## 金墨：三层结构（结构材料，不是金色图层）

金墨不是金色装饰，也不是均匀描边，而是一套三层结构：

1. **结构金线**：沿少量已有结构、裂隙或关键轮廓局部出现；不连续包边，不描摹所有轮廓。
2. **矿物金块**：作为主要视觉重量，集中附着于一个局部区域；边缘不规则，允许断裂、露墨、露纸。
3. **金颗粒**：从金块向外围逐渐减少；粗中细颗粒混合，密度递减，不形成均匀噪点。

整体关系：**聚集 → 过渡 → 散开**，只发生在同一个连续金墨区内部——散开是这一个区的收尾，不是全画散布。金墨必须与墨发生覆盖、穿插、留缝关系，不可成为独立的"金色图层"。

落点：一个主金墨区（主笔势、墨层转折或主焦点），必要时一至两个更小呼应。若借用原图真实光线（水面受光、首饰受光点、衣领转折），方向应有依据；不另造金色光源。

禁止：全画面细闪、均匀金粉、星星闪光、镜面金属、亮黄色、金色渐变、装饰性金点、多点分散铺开、立体金块浮雕。

**金墨与主墨势、空纸、视觉重心或摄影保护区发生冲突时，优先减少或删除金墨，不改变主体构图。**

金墨默认启用但保持局部。用户要求无金墨时关闭这一材料层，不影响笔墨和纸纹。

## 单一矿物强调色

黑白水墨是绝对主角（≥80% 面积），只保留一种高饱和强调色（≤10–15%）。默认选一个来自内容依据的色相，以矿物或植物颜料转译：朱砂 `#c3272b`、胭脂 `#9e3b4f`、石青 `#2a5c8a`、石绿 `#3e7a5e`、藤黄 `#e8b923`、赭石 `#a05a2c`、花青 `#3b4f8f`。可留空让模型按照片自动选。

让强调色有饱和度和起收笔，像毛笔一笔"写"出来——有起笔收笔、有笔锋飞白，沿已有形、方向或间隙承担导向、配重、衔接或焦点，成为构图的一部分而不是独立摆着的色块。它应是全画最抓人的一笔：高饱和、一笔到位、直击视觉。暗墨底上放高饱和的色让它在灰调里"跳"出来，但面积始终小。淡墨为主的画面，用饱和度特别高但占比特别小的颜色点睛。

允许同一颜料少量淡化回应，但只有一个高饱和主色相；最多一处小回声，回声不超过该强调色总面积的约 15%。执行结构移除测试：去掉颜色后，方向、平衡或焦点应有所损失；若完全不变，改变附着位置，而不是凭空增加有色物体。

统一口径：暖中性墨占可见着墨/着色标记的至少约 80%；普通矿物强调色不超过约 10–15%。金墨不占用"单一矿物色"的色相名额，但矿物色与金墨合计控制在约 20% 内。若颜色过多，先减彩色面积或增加已有墨势，不加新对象。禁荧光色、糖果色、纯 RGB 霓虹色。

内容是无彩色照片时，不声称观察到不存在的原色；先询问强调色，或保留暖中性墨与局部金墨，不擅自染出新的场景色。纯文字模式可按用户指定色或文字中的物体颜色选色。

## 留白与疏密

留白 ≥ 45%（计白当黑），**画面绝不铺满**；宁可留白偏多，不可画满。留白要承担"空间/呼吸/尺度/情绪"中至少一种功能，不是机械留边。个别作品可以较密，但必须有明显的"安静区"。

- 疏密对比：一密一疏引导视线（如左密右疏）。
- 主次靠墨色深浅 + 笔触繁简建立：主体用长笔势浓墨写形，次重点用淡墨线/简笔带过——重量来自墨色对比，不是"画得满"。
- 只做足 1–2 个主焦点：焦点用繁复笔触，次重点、中景用线条带过，不处处精致——细节做太足是"画面太满、留白不够"的主因。
- 繁简区分：复杂笔触与简单笔触要分开，次要/背景用简单笔触（写意、一笔带过），甚至只留一根线。

### 写意疏密（以疏导白）

水墨不是要求所有区域拥有相同的信息密度。在建筑、树木、街景等复杂区域，笔墨密度应随画面结构自然变化：

- 密处可以密，但不必处处同样密；
- 疏处不等于突然挖出一块空白，而是通过减少细节、拉开线条间距、简化形体、减弱墨量，让纸面逐渐重新显现；
- **"留白"优先通过"疏"产生**，而不是直接制造大片空白；
- 如果原图本身建筑密集，不要为了制造留白强行挖空建筑；应在建筑之间、建筑内部次要结构、远景层次或笔势收束处逐渐降低信息密度；
- 密 → 稍密 → 疏 → 更疏 → 空纸，是连续的视觉过渡，不是突然切换。

目标不是"画得少"，而是"画得有呼吸"。

### 简笔（形体信息压缩）

简笔用于降低局部视觉密度，**不是删除该区域的主体**。当一个区域已经承担足够的形体信息时：减少重复线条、合并相邻小结构、省略次级装饰、减少窗格/瓦片/枝叶等重复细节、用一笔或少量连续笔触概括原本复杂的结构。

必须保留：主体轮廓、大体比例、方向关系、明暗关系、主要结构节奏。

简笔后的形体仍然应该"像一个被画出来的东西"，而不是变成模糊、缺失或未完成的区域。简笔主要用于疏密过渡、远近关系和视觉呼吸。

### 疏密与墨色层级

疏密不仅通过线条数量控制，也通过墨色层级控制：

- **密处**：焦墨、浓墨、重墨，结构明确，笔触交叠；
- **过渡**：重墨减少、浓墨减少，线条开始分开，墨块缩小，湿墨变轻；
- **疏处**：淡墨、湿清墨、单线、简笔、大间距；
- **空纸**：不是"擦掉"，而是笔势自然停下。

## 现代气质

**现代水墨插画 / 编辑感，不是仿古画。** 用中国画的笔触（干湿浓淡焦）和材料（宣纸、矿物色、金墨），但画面气质是现代的、有空气感的、淡雅的。借鉴浓墨层次、疏密节奏、泼色与墨共存、动物传神等具体技法，不把画家姓名或仿古模板塞入提示词。不要题跋、印章、落款、均匀皴法或传统装裱感。严格避免：仿古做旧、满铺皴法、工笔细描到仿古程度、传统落款构图感。
